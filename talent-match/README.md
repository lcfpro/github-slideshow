# IT Talent Match — IT業界特化 人材×企業マッチングプラットフォーム

人（IT人材）と企業をつなぐ場所。入力の手間を極力なくし、テキストだけでない「リアルに近い体験」でマッチングから面接、組織づくりまで支援します。

```bash
cd talent-match
npm install
npm start            # http://localhost:3000 （初回起動時にデモデータを自動投入）
npm test             # ユニット + API テスト
npm run seed         # デモデータを作り直す
```

トップ画面で「応募者として始める」「企業として始める」を選ぶと、デモアカウントでログインできます。

## 要件と実装の対応

| # | 要件 | 実装 |
|---|------|------|
| 1 | 現実模擬（テキストだけにしない） | **バーチャル合同説明会**（Canvas の会場を歩き、ブースに近づくと担当者が話しかける）、**模擬面接ルーム**（面接官アバターが音声合成で質問 → 音声認識/テキストで回答 → 1問ごとに採点、カメラでセルフチェック）、職務経歴書・求人票を**紙面プレビュー**で表示、人物アバター、各種チャート |
| 2 | 入力を省く（ファイル抽出 + 豊富なテンプレート）— 応募者・企業の両方 | PDF / Word / Excel / CSV / TXT / Markdown / JSON / HTML をアップロード（複数可）すると自動抽出。画像（紙の履歴書の写真など）は Claude 有効時のみ対応。テンプレートは**職務経歴書 162種**（18職種×3レベル×3書式）、**求人票 216種**（18職種×3レベル×4企業タイプ）。抽出結果に近いテンプレートを推薦し、「選ぶ → 少し直す → 提出」で完了 |
| 3 | 双方向マッチング | スキル（必須/歓迎・レベル・近接スキル）50%、経験15%、年収15%、働き方10%、語学10% の説明可能なスコア。応募者の「興味あり」と企業の「スカウト」が両方そろうと**相互マッチ**が成立し、連絡先が開示される |
| 4 | 企業向け 面談アドバイス | 60分の進行案、強みの深掘り質問、ギャップ確認の質問、評価ルーブリック（採点入力つき）、条件のすり合わせ、候補者への訴求ポイント、NG質問（公正採用） |
| 5 | 応募者向け 面談前の準備 | 想定質問と回答のコツ、STAR形式のエピソード準備、補強すべきスキル、逆質問、年収交渉のポイント、前日チェックリスト → そのまま模擬面接へ |
| 6 | 人材市場の動態 | スキル需要ランキング・成長率、需要×供給の散布図、求人数の推移（スキルを選んで比較）、職種別の年収レンジ、働き方の比率、求人倍率。企業には**自社求人の競争力**（年収ポジション・母集団の大きさ・採用難スキル・改善提案）、応募者には**市場価値**（想定年収・上位何%か）を表示 |
| 7 | 企業向け 人的リソース管理 | スキルマトリクス（ヒートマップ・属人化リスク）、プロジェクト配置（不足スキル・社内アサイン候補）、稼働率・離職リスク推定、「育成で埋めるか採用するか」の提案（採用ならテンプレートから求人作成） |
| 8 | 応募者向け スキルアドバイス | 目標職種の要件カバー率、優先度（区分×市場ヒート×成長率÷習得コスト）順の学習リスト、12週間の学習プラン、次のレベルでの年収アップ額、伸びている隣接スキル |
| 9 | IT業界に限定 | 70以上のITスキル辞書（表記ゆれ対応）と18のIT職種マスタで構成 |

## Claude（生成AI）連携 — 任意

環境変数 `ANTHROPIC_API_KEY` を設定すると、次の機能が Claude（既定モデル `claude-opus-5-5`、`CLAUDE_MODEL` で変更可）で強化されます。未設定でもすべての機能がルールベースで動作します。

- 書類からの高精度な抽出（構造化出力）、画像（OCR）対応
- 候補者ごとの面談アドバイス・面接準備アドバイスの生成
- 模擬面接の回答採点とフィードバック

安全面の拒否（refusal）時にはサーバー側フォールバック（`fallbacks: "default"`）を有効化しており、それでも失敗した場合はルールベースの結果を返します。

## 構成

```
talent-match/
├── server/
│   ├── index.js        # Express API（認可・ルーティング）
│   ├── data/skills.js  # ITスキル辞書（表記ゆれ・需要・成長率・学習目安）
│   ├── data/roles.js   # IT職種マスタ（必須/歓迎スキル・年収レンジ・想定質問）
│   ├── extract.js      # ファイル → テキスト → 構造化（ルール / Claude）
│   ├── templates.js    # テンプレート生成・推薦
│   ├── matching.js     # マッチングスコア
│   ├── advice.js       # 面談アドバイス・準備・スキル・模擬面接採点
│   ├── market.js       # 市場分析
│   ├── hr.js           # 人的リソース管理
│   ├── ai.js           # Claude 連携（任意）
│   ├── store.js        # JSON ファイルストア（MVP用）
│   └── seed.js         # デモデータ（すべて架空）
├── public/             # フロントエンド（ビルド不要の ES Modules）
└── test/               # node:test によるテスト
```

## MVP としての制約と今後

- **認証はデモ用の簡易方式**（`x-user-id` ヘッダー）です。本番では OAuth / パスワード認証と CSRF 対策が必要です。
- データは `data/db.json` に保存します。本番では PostgreSQL などに置き換えてください（`store.js` のインターフェースを差し替える想定）。
- 市場データは、プラットフォーム内の実データと、デモ用に生成した月次スナップショットを組み合わせています。実運用では求人媒体や公的統計（例: 求人倍率）との連携が必要です。
- 音声入力は Web Speech API に対応したブラウザ（Chrome など）で利用できます。
